# Treino

App pessoal de treino (PWA): plano de 5 dias com foco em estabilidade lombar, registro de carga, recordes, timer de descanso e cronômetro. Funciona offline e os dados ficam salvos no próprio celular (faça backup pela aba Histórico).

## Instalar no celular
- **Android (Chrome):** abra o site → menu ⋮ → *Instalar app* / *Adicionar à tela inicial*.
- **iPhone (Safari):** abra o site → botão Compartilhar → *Adicionar à Tela de Início*.
